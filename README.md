# Pandas Practice

A structured collection of Python Pandas practice notebooks and datasets focused on data manipulation, cleaning, transformation, and analysis.

## 📌 About

This repository documents my hands-on practice with **Pandas**, one of the core Python libraries used in Data Science and Data Analysis.

It contains Jupyter Notebooks and supporting datasets covering fundamental to intermediate Pandas concepts through practical exercises and examples.

## 🧠 Topics Covered

- Creating and working with Series and DataFrames
- Inspecting and exploring datasets
- Selecting and filtering data
- Using `.loc` and `.iloc`
- Sorting and arranging data
- Data cleaning
- Handling missing values
- Removing duplicate data
- Data transformation
- Using `.apply()` and `.map()`
- Working with CSV, Excel, and JSON data
- Practical data manipulation exercises

## 🛠️ Tools & Technologies

- **Python**
- **Pandas**
- **Jupyter Notebook**
- **VS Code**
- **CSV / Excel / JSON**
